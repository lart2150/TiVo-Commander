DVR Commander is an open source Android app for controlling TiVo® DVRs, in the spirit of the [TiVo for iPad and iPhone](http://itunes.apple.com/us/app/tivo/id401673976?mt=8) app.

It is capable of connecting to and controlling a TiVo Premiere, Roamio, Bolt or newer device.
